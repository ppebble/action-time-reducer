# 검증 경계

## 소스/모의 실행

- 실제 42.21 Kahlua VM으로 모드 Lua 실행.
- 실제 게임 ISBaseObject/ISBaseTimedAction 및 지원하는 세 행동 클래스를 읽기 전용 로드.
- 단일플레이/client/server 각각 독립 VM 환경에서 98개 동작 검사와 재로드 검사.
- 100/200/400% 및 상하한, 옵션 끄기, 설정 미전달, 알려진 충돌, 반복 시간 조회, 동일 Type의 다른 클래스/파생 클래스 제외.
- 0/1/-1/비숫자/무한/NaN 시간값 보존, 가속 결과 최소 1 유지.
- 구체적인 생성자/완료/취소/검증 함수 및 create/adjustMaxTime 원본 참조 보존.
- EN/KO 번역 키 일치 및 금지된 강제완료·무게·전역 시간 조작 부재.
- 별도 읽기 전용 검토에서 서버의 생성자 인자 직렬화와 instance-local getDuration 접근 경로 확인.

모의 객체로 시간을 계산한 것이며 실제 재료 소모·XP·네트워크 결과가 올바르다는 실행 증거는 아닙니다. 로컬 설치 SHA-256 대조도 게임 로드/동작 증거가 아닙니다.

## 실제 2인 데디케이트 서버 시험 — 미실시

1. 서버와 두 참가자에 동일 버전 설치; 다른 행동 가속 모드는 비활성.
2. 동일 캐릭터/재료로 100%와 200%를 비교. 연출, 대기열 시작, 서버 결과 생성 시점을 각각 기록.
3. 일반 제작·B42 제작·지원 구조물 분해를 각각 단독/연속 실행.
4. 시작/중간/종료 직전 취소 및 재접속 후 수량·읽기/행동 상태 확인.
5. 두 플레이어의 동일 대상 동시 작업에서 거절/중복 생성/재료 손실 확인.
6. 부상·기분·특성에 따른 원래 시간 보정 유지 확인.
7. 현재 서버의 제작 레시피/분해 관련 모드와 함께 검사. 목욕·동물·독서·벌목·총기·건축·이동은 기본 시간 유지 확인.
8. 400%는 200% 검증 이후 시험. 설정을 접속/대기열 진행 중 바꾸지 않음.

이 시험을 통과하기 전에는 안정적인 MP 릴리스가 아닌 0.1.0 후보로 취급합니다.

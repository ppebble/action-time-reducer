# 서버 아이템 이동 수동 패치 — 0.4.2

대상은 Project Zomboid **42.21**입니다. 일반 모드는 싱글플레이 아이템 이동을 지원합니다. 이 추가 파일은 멀티 운영자만 설치하며, 참가자는 일반 모드만 사용합니다.

## 설치

1. 게임과 서버를 완전히 종료합니다.
2. 창작마당 다운로드가 완료되면 `SteamLibrary/steamapps/workshop/content/108600/<이 모드의 창작마당 ID>/mods/ActionTimeReducer/common/ServerPatch/classes`를 엽니다. ID는 창작마당 페이지 주소의 `id=` 뒤 숫자이며, 실제 Steam 라이브러리에 따라 앞부분 경로가 다릅니다. 다운로드에 `ServerPatch` 폴더가 없다면 다운로드 완료 여부와 배포 버전을 확인하세요.
3. `classes` 안의 **`zombie`, `actiontimereducer` 두 폴더**를 아래 대상에 복사합니다. `classes` 폴더 자체를 대상에 넣는 방식이 아닙니다.

| 실행 방식 | 대상 폴더 |
|---|---|
| Steam 데디케이트 서버 | `SteamLibrary/steamapps/common/Project Zomboid Dedicated Server/java` |
| SteamCMD 데디케이트 서버 | 지정한 서버 설치 폴더의 `java` |
| 게임 내 ‘호스트’ | `SteamLibrary/steamapps/common/ProjectZomboid` |

Steam 데디케이트 서버는 Steam 라이브러리의 **Project Zomboid Dedicated Server → 관리 → 로컬 파일 보기**에서 설치 위치를 확인할 수 있습니다. 일반 게임은 **Project Zomboid → 관리 → 로컬 파일 보기**를 사용합니다. 게임 내 호스트는 일반 게임 설치에서 서버 프로세스를 실행하므로 호스트 본인의 게임 폴더에 복사합니다. 데디케이트 운영자는 서버 쪽에만 복사하며 참가자의 게임 폴더에는 복사하지 않습니다.

복사 결과는 아래와 같습니다. `<대상>`은 위 표의 대상 폴더입니다.

```text
<대상>/zombie/core/Transaction.class
<대상>/actiontimereducer/server/TransferDuration.class
<대상>/actiontimereducer/server/TransferDuration$Access.class
```

**같은 이름의 파일이 이미 있으면 덮어쓰기 전에 확인하세요.** 다른 모드가 만든 `Transaction.class`와 병용하지 않습니다. 이 패치의 기존 버전임이 확인된 경우에만 교체하세요. 폴더 병합은 가능하지만 기존 파일 교체를 무조건 승인하지 마세요.

4. 서버 설정에서 일반 `ActionTimeReducer` 모드를 활성화하고 아이템 이동 단축률을 설정합니다. 서버 설정 화면에서 모드를 선택하거나 서버 INI의 `Mods`에 `ActionTimeReducer`, `WorkshopItems`에 이 모드의 창작마당 ID를 추가합니다. 기존 항목은 유지하세요. 기본 `0`은 원래 시간을 유지하며 숫자만 입력합니다. 허용 범위는 `0–95`이고, `30`은 약 30% 단축입니다. 서버와 참가자는 같은 일반 모드 버전을 사용해야 합니다.
5. 평소의 서버 실행 파일이나 게임 실행 방식으로 시작합니다. 배치 편집·PowerShell 설치·agent·추가 로더는 필요 없습니다.

`C:/Users/<사용자>/Zomboid` 설정·세이브 폴더는 복사 대상이 아닙니다. 원본 `projectzomboid.jar`는 교체하지 않습니다. 복사한 클래스가 JAR 안의 원본 클래스보다 먼저 읽히는 방식입니다. 호스트 게임에서 싱글을 시작하면 서버 여부 검사로 Java 보정을 건너뛰므로 Lua 보정과 중복 적용하지 않습니다.

## 업데이트와 해제

게임을 업데이트하면 **복사한 클래스가 남아 새 게임 코드보다 먼저 로드될 수 있습니다.** 관련 코드가 바뀐 버전에서는 오류가 나거나 새 수정이 반영되지 않을 수 있으며, 모드를 비활성화해도 클래스 호환성 문제는 남습니다. 현재 패치는 agent 방식의 런타임 지문 불일치 차단을 제공하지 않습니다.

게임 업데이트 전 또는 새 버전 지원 여부가 불확실할 때, 게임/서버를 종료하고 위 **세 파일만** 제거해 원래 동작으로 복구하세요. 새 지원 버전이 준비되면 새 파일을 다시 복사합니다. 창작마당 업데이트는 수동 복사본을 자동 갱신하지 않습니다.

해제 시 `zombie` 폴더 전체를 지우지 마세요. 다른 파일은 유지하고 위 세 파일만 제거합니다. 비어 있는 자체 `actiontimereducer/server` 폴더는 제거할 수 있습니다. 일반 Lua 모드의 싱글 기능은 별도로 유지할 수 있습니다.

## 동작과 확인 범위

서버의 `Transaction.getDuration()` 최종 결과에 설정한 배율을 적용합니다. 원래 특성·무게·장갑 보정, 거래 승인·완료·취소·용량 검사와 패킷 형식은 유지합니다. 서버가 줄어든 기간을 보내면 참가자의 원래 클라이언트가 사용합니다. 모드 미활성·설정 0·설정 누락·알려진 충돌에서는 원래 기간을 반환합니다.

이 배포에는 사용자 요청에 따라 수정한 원본 `Transaction.class` 한 개와 자체 작성한 보정 클래스 두 개가 포함됩니다. 원본 게임 JAR 전체나 다른 원본 클래스는 포함하지 않습니다. 기준 원본 SHA-256:

```text
107B0A554CC46D1015398FF283A2E48FAF02EFBC44ADF12854F66394EE2487B6
```

사용자 플레이에서 싱글 적용과 패치된 데디케이트 서버의 아이템 이동 적용을 확인했습니다. 일반 클라이언트에 설치했던 Java 패치도 제거했습니다. 다만 제거 이후의 플레이 성공을 별도로 확인한 증거와 **게임 내 호스트 부팅 및 두 클라이언트의 이동·취소·결과 동기화 검증은 아직 없습니다.** 클래스 우선 로드와 오프라인 계산 검사만으로 이러한 플레이 검증을 대신하지 않습니다. 멀티 새 건축 배치는 이 패치 대상이 아닙니다.

# Action Time Reducer — 0.5.1

Project Zomboid **42.21**용 바닐라 행동시간 단축 모드입니다. 캐릭터 특성, 무게, 전역 게임시간을 변경하지 않습니다. 원래 완료·취소·소모·XP 경로를 유지하고, 정확히 허용한 행동 클래스만 조정합니다.

## 샌드박스 설정

**행동시간 단축** 설정 페이지 하나에서 **76개 행동별 옵션**을 각각 조정합니다. 체크박스 형태의 구분선 11개로 섹션을 나눕니다. 구분선의 체크 여부는 행동시간에 영향을 주지 않습니다. 모든 기본값은 **0**입니다.

- `0`: 원래 시간 유지. `10`: 약 10% 단축. `30`: 약 30% 단축.
- 입력 범위 `0–95`. % 기호를 입력하지 않습니다. 완전한 즉시 완료는 제공하지 않습니다.
- 싱글에서는 플레이 중 샌드박스 설정을 바꾸면 새로 생성하는 행동부터 반영됩니다. 이미 진행 중이거나 큐에 생성된 행동은 취소 후 다시 시작하세요. 멀티 설정 변경 후에는 서버를 재시작하세요.

| 설정 섹션 | 개별 조정 가능한 행동 예시 |
|---|---|
| 제작·연구 | 일반 제작, B42 수작업 제작, 통나무 톱질, 제작법 연구 |
| 건축·해체·벌목 | 건축, 구조물 철거·분해, 바리케이드, 페인트·미장·벽지, 벌목 |
| 의료 처치 | 붕대·소독·봉합·부목·이물질 제거·약 복용 |
| 의복·생활용품 | 옷 입기, 의복 수선, 아이템·발전기 수리 |
| 차량 정비 | 부품 설치·제거·수리, 엔진 작업, 타이어 작업 |
| 위생·세탁 | 바닐라 몸 씻기, 옷·붕대 세탁 |
| 독서 | 기술서·잡지 등 |
| 음식·음료·흡연 | 음식·음료 섭취, 바닐라 담배·시가 |
| 액체·연료 이동 | 물 받기, 액체 이동·비우기, 주유·연료 이동 |
| 축산·도축 | 착유·털 깎기·급수·먹이·축사 청소·도축·사체 가공 |
| 아이템 이동 | 가방·인벤토리·컨테이너 사이 이동. 멀티는 운영자 수동 패치 필요 |

76개 옵션은 74개 바닐라 행동 클래스와 별도로 구분한 흡연에 대응합니다. 먹기와 흡연도 각각 조정합니다. 실제 지원 범위는 `ATR_Core.lua`의 정확한 클래스 허용 목록입니다. 모드의 파생/교체 클래스 및 알 수 없는 행동은 자동 지원하지 않습니다.

**0.4.2에서 업데이트:** 이전 카테고리 값은 새 행동별 옵션으로 자동 적용되지 않으며 새 옵션은 0으로 시작합니다. 기존 `InventoryTransfer` 옵션은 키가 같으므로 설정값을 유지합니다.

## 설치와 지원 경계

**싱글플레이는 일반 모드만 필요합니다. 멀티 아이템 이동은 운영자만 클래스 파일을 수동 복사합니다.** 참가자는 같은 버전의 일반 모드를 사용하며 Java 패치를 설치하지 않습니다. 서버 패치가 없으면 멀티 아이템 이동은 기본 시간을 유지합니다.

**0.5.0은 Java 패치를 변경하지 않습니다.** 같은 42.21 환경에 호환되는 0.4.2 패치가 이미 설치되어 있다면 다시 복사할 필요가 없습니다.

게임·서버를 완전히 종료하고, 대상 경로에 같은 이름의 파일이 있다면 출처를 확인하여 설치 폴더 밖에 먼저 백업하세요. 그다음 배포물의 `mods/ActionTimeReducer/common/ServerPatch/classes` 안에 있는 `zombie`, `actiontimereducer` 두 폴더를 다음 위치에 복사합니다. 기존 실행 파일과 Steam 실행 방식은 그대로 사용하며, 별도 agent·로더·설치 프로그램·배치 편집이 필요 없습니다.

| 실행 방식 | 복사 대상 |
|---|---|
| 데디케이트 서버 | 서버 설치 폴더의 `java` 폴더 |
| 게임 내 ‘호스트’ | 일반 `ProjectZomboid` 게임 설치 폴더 |

서버/게임을 종료한 뒤 복사하세요. 정확히 같은 대상 파일이 이미 있다면 다른 Java 패치인지 확인하기 전에는 덮어쓰지 마세요. [수동 설치·해제 안내](server-patch/manual-README.md)에 파일 목록과 경로를 명시했습니다.

원본 게임 JAR은 유지하지만 수정한 `Transaction.class`가 먼저 로드됩니다. 모드 비활성·설정 0일 때 시간 보정은 하지 않습니다. **게임 버전이 맞지 않으면 모드 비활성 서버에도 오류가 생길 수 있습니다.** 게임 업데이트 뒤 기존 복사본을 제거하고 새 지원 버전을 확인하세요. 창작마당 업데이트가 서버/게임 폴더의 수동 복사본까지 교체하지는 않습니다.

**멀티의 새 건축 배치(ISBuildAction)는 미지원입니다.** 싱글플레이에서는 보정하며, 멀티의 Lua 다단계 건축, 철거, 분해, 바리케이드·마감, 벌목은 별도 지원 경로입니다.

벌목은 원래 서버 타격 간격과 자체 애니메이션 노드의 속도를 보정합니다. 노드는 원래 게임 애니메이션을 이름으로 참조합니다. 타격 피해량·내구도·지구력·완료 처리는 원래 코드가 수행합니다. 축산 반복 작업은 원래 처리 간격만 줄입니다. 애니메이션 전환·서버 처리 주기·최소 시간 때문에 실제 단축률은 입력값과 약간 다를 수 있습니다.

외부 샤워 행동, 가구 이동/분해, 총기 부착물·재장전, 혈흔/낙서 청소, 농사, 채집, 덫/어망, 수건 건조, 무기 꺼내기/핫바, 세차, 낚시, 운동, 휴식은 제외합니다. 수면·조리·성장·발효 등 세계 시뮬레이션 시간도 변경하지 않습니다.

## 검증 상태

Mod ID: `ActionTimeReducer`. 서버와 모든 클라이언트에 같은 일반 모드 버전을 설치하세요. 다른 행동 가속 모드와 병용하지 마세요. 알려진 충돌 모드는 차단되지만 모든 외부 충돌을 검출하지는 않습니다.

이전 0.4.2에서는 Lua 검사 1,251개와 동일한 Java 패치에 대한 서버 계산·바이트코드 검사 39개가 통과했습니다. 클라이언트·데디케이트의 내장 Java에서 agent 없는 클래스 로드, 자식 프로세스 로드 및 원본 복귀를 확인했습니다. 사용자가 싱글·데디케이트에서 시간 단축 및 상자 제작 단축을 확인했습니다. 게임 내 호스트는 호스트 입장에서만 테스트했습니다. **서로 다른 컴퓨터의 여러 클라이언트 동시 플레이와 전체 애니메이션은 아직 검증하지 않았습니다.** 0.5.0은 Kahlua 검사 18,145개 및 76개 옵션·양언어 번역·설정 페이지 검사를 통과했습니다. Java 패치 검사 39개도 다시 통과했습니다. 상세 결과는 [verification.md](docs/verification.md)를 참고하세요.

배포물은 저장소 내부에서 준비합니다. 이후 사용자 요청으로 기존 로컬 모드 0.1.0을 백업하고 0.4.2으로 갱신했으며, 별도 캐시의 로컬 테스트 서버를 준비했습니다. 기존 서버 INI·프리셋·세이브와 원본 게임 JAR, Workshop 업로드는 변경하지 않았습니다. [building-transfer.md](docs/building-transfer.md)에 서버 계산 경로와 제한을 설명합니다.

## 창작마당 업로드 준비

창작마당 기본 영어 설명은 [workshop-description-en.bbcode](docs/workshop-description-en.bbcode), 한국어 설명은 [workshop-description-ko.bbcode](docs/workshop-description-ko.bbcode)에 있습니다. scripts/stage-workshop.ps1은 일반 모드와 ServerPatch를 함께 업로드 폴더에 준비하고 내용을 해시 검사합니다. Steam 공개나 업로드는 실행하지 않습니다. 새 업로드용 메타데이터의 기본 공개 범위는 비공개입니다.

## 선택적 카트 호환 (0.5.1)

아이템 이동 섹션의 카트 아이템 이동(SaucedCarts) 옵션은 항상 표시되며, SaucedCarts가 활성화된 경우에만 정확한 ISCartTransferAction에 적용됩니다. 기본 0, 범위 0~95입니다. 일반 아이템 이동 값과 독립적입니다. 카트 동작에는 Java 패치가 필요하지 않습니다. SaucedCarts의 생성자·완료·취소·일괄 이동 코드는 변경하지 않습니다. 설치된 2.1.20 코드를 사용한 Kahlua 검사에서 SP/client/server의 시간 계산·중복 보정 방지·비활성·0 설정을 확인했으며 실제 멀티 플레이는 미검증입니다.

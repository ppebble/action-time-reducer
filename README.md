# Safe Action Time — 0.1.0

Project Zomboid **42.21**용 선택적 행동시간 단축 모드. 독립 Lua 구현이며 Java 파일이나 다른 모드 원본을 교체하지 않습니다.

## 현재 지원

| 행동 | 실제 대상 |
|---|---|
| 일반 제작 | ISCraftAction |
| B42 수작업 제작 | ISHandcraftAction |
| 일부 구조물 분해 | ISDismantleAction — 모든 가구/차량 분해를 뜻하지 않음 |

샌드박스의 **선택적 행동시간 단축**에서 사용 여부, 제작/분해 가속, 속도 100–400%를 설정합니다. 기본값 200%는 소요시간 절반입니다. 설정값이 아직 전달되지 않았으면 기본 시간으로 동작합니다. 접속 전 설정하고, 배율 변경 후 서버와 클라이언트를 재시작하세요.

건축, 아이템 이동, 독서, 벌목, 동물, 목욕, 총기 행동 및 알 수 없는 행동 클래스는 가속하지 않습니다. 모드가 추가한 레시피라도 지원하는 제작 클래스를 이용한다면 가속됩니다. 이는 모든 레시피 콜백의 안전성이 검증됐다는 뜻이 아닙니다.

## 멀티 구조와 제한

서버와 모든 클라이언트에 같은 버전을 설치해야 합니다. shared Lua에서 행동 객체의 getDuration만 조정합니다. 서버가 원래 경로로 시간을 계산하고 결과를 처리하도록 유지합니다. 구체적인 행동의 new 생성자, complete/perform/stop, 재료 소모, XP, 부상/기분에 따른 시간 보정은 변경하지 않습니다.

다른 행동 가속 모드와 함께 사용하지 마세요. 알려진 가속 모드 다섯 개는 mod.info의 incompatible 및 런타임 검사로 차단합니다. 목록에 없는 가속 모드나 클래스 교체까지 자동 검출하지는 못합니다.

**멀티 호환을 목표로 구현한 테스트 후보이며, 실제 2인 데디케이트 서버 검증은 아직 하지 않았습니다.** Kahlua의 client/server 모의 문맥은 네트워크 접속 시험이 아닙니다. 재료·결과 수량, 중단/재개, 동시 작업 및 재접속 검증 전에는 무오류를 보장할 수 없습니다.

## 설치/활성화

Mod ID: `SafeActionTime`. 로컬 설치 위치: `C:/Users/ask13/Zomboid/mods/SafeActionTime`.

서버와 모든 참가자의 로컬 mods 폴더에 동일한 `SafeActionTime` 폴더를 넣고 모드를 활성화해야 합니다. 로컬 모드는 Workshop에서 자동 배포되지 않습니다. 이 버전에는 Workshop ID가 없으며 업로드하지 않았습니다. b42211002의 Mods/WorkshopItems 및 세이브는 이번 작업에서 변경하지 않습니다.

기존 저장 프리셋 b42211002에는 TwisTonFireFasterActions가 남아 있으므로, 프리셋을 적용할 때 함께 활성화하지 않도록 주의하세요. 실제 서버 INI와 저장 프리셋은 별개입니다.

## 개발/검증

`scripts/test.ps1`: 설치된 게임의 Kahlua VM과 원본 행동 Lua를 직접 로드하고, 게임 객체를 모의한 테스트를 실행합니다. 게임 파일은 수정하거나 묶음에 재배포하지 않습니다.

`scripts/install-local.ps1`: 새 설치 폴더만 생성하며 기존 설치가 있으면 중단합니다. `-VerifyOnly`는 파일 목록·SHA-256만 대조합니다.
